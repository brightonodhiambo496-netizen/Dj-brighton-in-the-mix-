CROSS DJ PRO
============
Your app (edit these 3 files):  app/src/main/assets/
  index.html  = screen layout
  style.css   = colours and look
  app.js      = all the DJ features (sections are labelled at the top)
  logo.png    = logo (app icons are in app/src/main/res/mipmap-*)

Preview in a browser: open assets/index.html in Chrome.

Get the APK with GitHub:
 1. Upload everything in this folder to your repo (include the .github folder).
 2. Actions tab > "Build APK" > wait for the green tick.
 3. Open the run > Artifacts > CrossDJPro-apk > unzip > install app-debug.apk.
